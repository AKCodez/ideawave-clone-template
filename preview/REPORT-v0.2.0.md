## The four directions

- **editorial** (dark, Instrument Serif over Inter Tight, amber 42): a magazine cover.
  Masthead rule with the kicker left and the brand adjectives right, one 92 px serif
  headline across the full measure, a narrow standfirst beside the product frame.
  Hairline rules, near-square corners, text wiping up from behind a mask over 640 ms.
- **luminous** (dark, Space Grotesk over Geist, blue 232): a keynote. Centred, lit from
  behind by a drifting aurora, pill badge, springy headline, the product below the fold
  on a tilted glass pane with a glow ring. Traffic-light browser chrome, magnetic primary
  button.
- **brutal** (light, Bricolage Grotesque over Manrope, green 145): a printed poster.
  Flush left, zero radius, 2 px black rules, a solid green kicker block, a full-bleed
  ticker of the brand's own phrases between headline and product. Hard offset shadows
  that shift on press. Motion snaps in five visible steps.
- **craft** (light, Newsreader over DM Sans, terracotta 24): a well-made book. Warm paper
  canvas, reading serif, two columns with the frame on a page-lift shadow, medium
  corners, a calm 616 ms fade and rise, a CTA on a paper panel.
- editorial-light and luminous-light are the same compositions on the light ramp with
  Fraunces and Geist.

## Three defects found by looking at rendered pages

1. A `clip-path` that hides an element collapses its IntersectionObserver ratio to zero,
   so a mask reveal never crossed a threshold above 0 and everything nested inside stayed
   clipped. The landing page rendered as a column of empty boxes. Mask directions now use
   a zero viewport threshold (`REVEAL_AMOUNT` in `src/components/motion/provider.tsx`).
2. A Tailwind theme key named after a CSS keyword overrides a core utility:
   `--spacing-block` emitted `.inline-block { inline-size: ... }` and collapsed every
   inline-block to 43 px (a headline missing most of its letters). The token is
   `--spacing-stack`; a test fails on any token named after a CSS keyword.
3. A field read off the `as const` brand import is the literal one build happens to use,
   so `brand.scheme === "dark"` typechecked here and would fail tsc for every other
   brand. Components read `tokens.brand`; a test forbids the pattern.

## Deviations from the plan

- Contrast floors raised: accent 4.5:1 against canvas and surface (small text is set in
  the accent), faint 4.5:1, muted and faint solved against the worst of surface, elevated
  and accent-soft, status colours solved against a 12 percent wash of themselves.
- `--space-block` is `--spacing-stack`; section rhythm takes half the token per side.
- Lighthouse is not run (not installed; outside the dependency allowlist). axe runs on `/`
  and `/sign-in` for all six presets.
- `@better-auth/cli` removed (unreferenced; its peer chain crashed `npm install`);
  `@types/node` to ^22 for vitest 5.
- The example feature is Snippet with migration `0002_snippets`; ProductFrame, seed and
  demo data show the same rows.
- `tokens.fonts.ogFile` is a single display face; OG body text always uses Geist.
- `StaggerItem` is exported by name (`Stagger.Item` throws in a server component).
- Two extra scripts: `scripts/shoot.mjs` and `scripts/brand-set.ts`.
- `SiteHeader` is re-exported from the sections barrel.
- `preview/shots`, `preview/og`, `preview/audit` are gitignored: the sandbox clones this
  repo on every build.

## What the pipeline must match

- Contract: `src/design/types.ts` and `src/design/brand-schema.ts` mirror IdeaWave's
  `src/lib/clone/kit.ts` verbatim, `KIT_CONTRACT_VERSION "0.2.0"`. `src/brand.ts` is exactly
  what `renderBrandTs` emits; `scripts/brand-set.ts` uses the same renderer.
- Preview env: `DATABASE_URL`, `DIRECT_URL`, `BETTER_AUTH_SECRET`, `NEXT_PUBLIC_APP_URL`,
  `APP_URL`, `APP_NAME` (falls back to `brand.name`), `DEMO_MODE=1`, `AI_GATEWAY_API_KEY`,
  `AI_MODEL` (default `anthropic/claude-sonnet-5`), `AI_MODEL_FALLBACK` (default
  `openai/gpt-5-mini`), `AI_TIMEOUT_MS` (default 30000). `DEMO_MODE` is not public: the
  root layout passes `features.demo` into `<DemoBanner enabled>`.
- AI: `src/lib/ai.ts` calls the gateway over plain fetch at
  `POST https://ai-gateway.vercel.sh/v1/chat/completions`. The `ai` package and `@ai-sdk/*`
  are not installed and must not come back.
- Audit env for `build.sh`: `AUDIT_BASE`, `AUDIT_PAGES` (JSON array of paths; `"!/nope"`
  means a 404 is expected), `AUDIT_OUT`, `AUDIT_PASS`, `AUDIT_DEMO_EMAIL`,
  `AUDIT_DEMO_PASSWORD`. Writes `report.json` (`{pass, ok, score, counts, findings,
  screenshots}`; findings carry `severity`, screenshots carry `name` and `file`) and
  `report.md`, exits 0 even with findings. Paths matching `/(dashboard|settings|app)` are
  shot signed in through `POST /api/auth/sign-in/email`.
- Timing: verify 20 s cold, tests 1.3 s, one build about 12 s, the six-preset preview
  about 6 minutes.
- Migrations: the build sandbox has no database and no shadow database, so the agent
  diffs schemas, never URLs (see CLAUDE.md step 2).
- `design:check` exit codes: 2 forbidden strings and raw colours, 3 landing composition,
  4 renames, 5 generated files out of sync, 6 feature bar, 7 missing asset routes. Build
  mode is detected by `.clone/SPEC.md` existing.
